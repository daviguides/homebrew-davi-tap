# Davi's Homebrew Tap

Personal Homebrew tap for CLI tools and formulas.

## Installation

First, tap the repository:

```bash
brew tap daviguides/homebrew-davi-tap
```

Then, install any available formula:

```bash
brew install rabbitmqadmin
```

## Available Formulas

- `rabbitmqadmin`

## Notes

All formulas in this repository are personally curated and verified.

This repository also includes a GitHub Action to lint and validate formulas automatically:

- [Homebrew Lint Workflow](.github/workflows/lint.yml)
